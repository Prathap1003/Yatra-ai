## 📌 About the Project

**YATRA AI** is an AI-assisted smart tourist guide and travel planning web application designed to simplify the travel planning experience.

It helps users create personalized travel itineraries based on their destination, budget, travel duration, number of travellers, food preferences, accommodation preferences, and travel interests.

The application aims to organize tourist attractions into day-wise schedules and provide destination-related information, making travel planning easier and more convenient.

## 🎯 Objectives

- Generate personalized travel itineraries.
- Provide destination-based travel recommendations.
- Organize tourist attractions into day-wise schedules.
- Consider user budgets and travel preferences.
- Simplify travel planning through a centralized platform.
- Support modifications to travel plans when requirements change.

## ✨ Key Features

- **Smart Trip Planning:** Enter your destination, budget, and travel duration.
- **Personalized Itinerary:** Prepare travel schedules based on user preferences.
- **Trip Analysis:** Consider traveller count, food preferences, and travel interests.
- **Destination Information:** Display photographs and information about tourist attractions.
- **Travel Dashboard:** Access different travel-planning modules.
- **Emergency & Safety:** Provide an interface for emergency-related assistance.
- **Adaptive Travel Planning:** Designed to support itinerary modifications.

*Note: Feature availability depends on the current implementation of each application module.*
